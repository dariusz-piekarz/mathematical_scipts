# Archiwum pierwotnej teorii modeli

Zachowano wszystkie 19 rozdziałów oraz niezmieniony punkt wejścia. Archiwum nie należy do katalogu Atlasu. Pełny audyt różnic merytorycznych i historycznych etykiet jest nadal wymagany; wycofanie z katalogu nie oznacza potwierdzenia pełnego pokrycia. Kompilacja z `books/pl/` zachowuje względne ścieżki oryginału.
