# AA-54 — zakres

Pierścienie niezmienników 2T,2O,2I w modelach AA-52, szeregi Hilberta z AA-53, jawne generatory, relacje i kompletność, równania E6,E7,E8. Poza zakresem: pełna klasyfikacja osobliwości, rozwiązania minimalne, odpowiedniość McKaya. Wymagane niezależne audyty, dwa zestawy regresji, pełny CI i oględziny PDF.
