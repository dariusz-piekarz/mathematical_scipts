# Functional analysis (Polish)

This module contains 35 chapters and supplemental modules after the second mathematical audit.

Build: `cd books/pl && latexmk -pdf -interaction=nonstopmode -halt-on-error functional_analysis.tex`.

The source is in Polish, while directory identifiers and maintenance descriptions are in English. Chapter labels are preserved for cross-references.
