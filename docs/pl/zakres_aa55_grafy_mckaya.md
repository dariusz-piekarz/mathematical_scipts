# AA-55 — zakres

Grafy McKaya dla skończonych podgrup SL2(C): symetria, spójność, dodatni wektor wymiarów, klasyfikacja kombinatoryczna afinicznych diagramów ADE, jawna identyfikacja wszystkich rodzin oraz rysunki, rozkłady iloczynów tensorowych z naturalną reprezentacją, potęgi symetryczne i szeregi Hilberta. Bez geometrii rezolucji minimalnych i bez pełnych tablic charakterów grup wyjątkowych. Dwa niezależne audyty, pełne regresje i PDF.
