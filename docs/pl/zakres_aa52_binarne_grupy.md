# AA-52 — zakres

Klasyfikacja skończonych podgrup SL2(C), sprzężenie, grupy dwucykliczne i binarne wielościenne, naturalna reprezentacja i półniezmienniki orbit. Nie obejmuje pełnych tablic charakterów i odpowiedniości McKaya. Wymagane niezależne audyty, dwa zestawy regresji, pełny CI, przegląd PDF.
