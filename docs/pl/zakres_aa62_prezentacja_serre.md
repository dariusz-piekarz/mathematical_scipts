# AA-62 — zakres

Pełny dowód twierdzenia o prezentacji Serre'a i istnienia półprostej algebry Liego dla każdego skończonego zredukowanego krystalograficznego układu korzeni. Konstrukcja wolna, gradacja, odbicia, górne ograniczenie wymiaru, moduły i dolne ograniczenie, półprostota i jednoznaczność przy zadanej macierzy Cartana. Sprzężoność maksymalnych podalgebr toralnych oraz pełna klasyfikacja bez wyboru podalgebry pozostają odrębnym etapem.
