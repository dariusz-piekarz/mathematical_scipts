# AA-60 — zakres

Skończenie wymiarowe reprezentacje sl2: klasyfikacja nieprzywiedlnych, pełna redukowalność przez operator Casimira i rozszczepienie, krotności, model wielomianowy, jednowymiarowość i zredukowanie korzeni, ciągi korzeniowe, odbicia, liczby Cartana, rzeczywisty model euklidesowy, przykład A2. Bez ogólnego twierdzenia Weyla, sprzężoności podalgebr Cartana i klasyfikacji algebr półprostych. Wymagane dwa czyste audyty, dwa zestawy regresji, pełne CI i kontrola PDF.
