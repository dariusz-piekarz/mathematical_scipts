# AA-59 — zakres

Rozkład Jordana derywacji, maksymalne podalgebry toralne i ich samonormalizowanie, rozkład korzeniowy, parowanie Killinga, nieizotropowość korzeni w sensie alfa(t_alfa) != 0, trójki sl2, przykład sl3 z diagramem A2. Ciało algebraicznie domknięte charakterystyki zero. Bez odwrotnej charakterystyki podalgebr Cartana, sprzężoności, wymiarów przestrzeni korzeniowych, teorii reprezentacji sl2 i pełnej klasyfikacji. Wymagane dwa czyste audyty, niezależne regresje, pełny CI oraz oględziny PDF.
