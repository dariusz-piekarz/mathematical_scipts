# CAT-11 — regresje

| ID | Kryterium | Metoda |
|---|---|---|
| CAT-11-001 | Transpozycja i odwrotność | Enumeracja funkcji, także puste zbiory |
| CAT-11-002 | Naturalność w X | Enumeracja prekompozycji |
| CAT-11-003 | Zmiana podstawy i wykładnika | Składanie funkcji |
| CAT-11-004 | Implikacja w algebrze Boole'a | Wszystkie trójki podzbiorów |
| CAT-11-005 | Przeszkoda obiektu zerowego | Endomorfizmy jednowymiarowych przestrzeni nad F_p |
| CAT-11-006 | Rachunek wykładników | Liczności skończone, także 0^0 |
| CAT-11-007 | Topologia zwarto-otwarta | Skończone przestrzenie dyskretne |
| CAT-11-008 | Struktura | Etykiety i środowiska |
