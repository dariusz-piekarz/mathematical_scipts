# Iteration VI: chapter dependency audit

Date: 2026-11-19. Branch: `biblioteka-matematyczna-iteracja-6`.
Scope: all 357 TeX files under `chapters/pl/` (355 numbered chapters and two
measure-theory supplements), all 16 book entrypoints, three shared modules,
`catalog/books.json` and `catalog/topic_registry.json`.

## Findings and repairs

- **Two missing images** in `partial_differential_equations/28-rownania-naviera-stokesa.tex`:
  `figures/taylor_green_3d_slices.png` and
  `figures/taylor_green_3d_schematic.png`. Both have been replaced by inline
  TikZ diagrams directly computed or schematically motivated from the stated
  Taylor–Green initial velocity. No external file is needed to typeset them.
- **One unbundled code reference** in the same figure caption,
  `scripts/taylor_green_3d_plot.py`, was removed. The PDE book preface no
  longer requires the unbundled `scripts/listings/` archive or the missing
  `INSTRUKCJA_URUCHOMIENIA.md` and `MAPA_ZALEZNOSCI_TOM_I.md` files.
  Numerical listings remain embedded in the TeX sources.
- **Six internal `\input` calls** in three chapters import three existing
  files from `shared/pl/`: the weak Lefschetz theorem and normal/cohomological
  blow-up modules. These are intentionally canonical shared resources and
  **are not independently complete chapter files**. Their files exist, are
  wholly inside the GitHub repository, and contain no further external asset
  imports. They were not copied into multiple chapters, to avoid content
  duplication and label drift.
- **All 16 book entrypoints:** their `\input` file sets and numbered chapter
  order agree with `catalog/books.json`; no dangling chapter import was found.
  Measure-theory supplements are deliberately before and after the main chapters.
- **Five stale source paths** in `catalog/topic_registry.json` were corrected
  to match the iteration-VI renames. Shared-module targets still marked as
  pending were not falsely treated as existing files.
- **Twelve `xr-hyper` cross-volume references** in the four probability
  book entrypoints previously used missing old `.aux` basenames.
  They now use the canonical `probability_volume_i` through `_iv`
  basenames. Each is conditional on the corresponding sibling `.aux`,
  allowing a clean standalone first build; cross-volume links become
  available on subsequent builds after sibling volumes are compiled.
- **Letter-suffixed chapter IDs:** `FA-15A` and `FA-15B` are both present
  and are parsed by the indexer. The generator previously rejected their
  IDs; its validation pattern now accepts the established `NN[A/B]` form
  and has a regression test.

## Structural checks

The tree contains **355 registered chapters, 2 registered supplements,
16 book entrypoints, and 3 shared TeX files**. All 355 canonical chapter
IDs are distinct and valid. The older offline app description still reports
352 bundled indexed chapters; a rebuild from the repository's canonical
`chapters/pl/` tree should take the 355 numbered chapters and exclude the
two supplements. The prebundled offline snapshot is not regenerated by
this commit.

## Prevention and verification

`tools/audit_chapter_dependencies.py` now checks numbered filenames,
catalog/entrypoint agreement, orphan files, registry source paths, and
external graphics/code/bibliography inputs. It ignores comments, inline
verbatim/listing content, and self-contained TikZ illustrations.
`tools/validate_repository.py` invokes it during regular validation.
Its isolated synthetic checks passed locally (six cases), and both new
Taylor–Green TikZ figures compiled in a standalone TeX smoke test.

Run from the repository root:

```sh
python tools/audit_chapter_dependencies.py
python tools/validate_repository.py
python -m unittest discover -s tools/tests -v
```

**Limitations:** The complete checkout was not available to run all original
application tests or to compile every book during this audit. These are
static file checks plus local figure/unit-test smoke tests. Standard TeX
packages, and optional Python packages when running numerical listings,
are still toolchain prerequisites; they are not missing chapter assets.
The previously reported **303 duplicate label names and 17 unresolved
cross-references** remain a separate, unclosed mathematical audit backlog.
