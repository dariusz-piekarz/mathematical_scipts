## Kontrola pomocnicza FA24-SYM-105-01
Rzeczywiście uruchomiono lokalnie poniższy kod w Pythonie z Fraction: trzy przedstawienia rank-one operatorów A:l-infinity^2 -> l1^2, po 625 macierzy U reprezentujących tensory z drugim czynnikiem l1^2. Epsilon(U) jest maksimum norm l1 wierszy (dual pierwszego czynnika to l1, drugiego l-infinity); pi(AU) jest sumą modułów wpisów. 3750 oszacowań wektorów współczynników, 1875 tożsamości rekonstrukcji i 1875 oszacowań pi <= C epsilon; razem 7500/7500. To skończone modele, nie dowód ogólny ani dodatkowa metoda CI.

```python
from fractions import Fraction as F
from itertools import product
models=[(((F(1,2),F(-1,3)),(2,-1)),((F(2,3),F(1,4)),(1,3))),
        (((1,1),(1,-1)),((1,-1),(2,1))),
        (((0,0),(1,2)),((F(1,3),F(-2,3)),(0,-2)))]
def l1(v): return sum(map(abs,v))
counts=[0,0,0]
for model,e in product(models,product(range(-2,3),repeat=4)):
    U=(e[:2],e[2:]); eps=max(map(l1,U))
    A=tuple(tuple(sum(a[i]*ell[j] for a,ell in model)
                  for j in range(2)) for i in range(2))
    AU=tuple(tuple(sum(A[i][k]*U[k][j] for k in range(2))
                   for j in range(2)) for i in range(2))
    rows=[tuple(sum(ell[i]*U[i][j] for i in range(2))
                for j in range(2)) for a,ell in model]
    for (a,ell),v in zip(model,rows):
        assert l1(v)<=l1(ell)*eps
        counts[0]+=1
    reconstructed=tuple(tuple(sum(a[i]*v[j] for (a,ell),v in zip(model,rows))
                              for j in range(2)) for i in range(2))
    assert AU==reconstructed
    counts[1]+=1
    C=sum(l1(a)*l1(ell) for a,ell in model)
    assert sum(map(l1,AU))<=C*eps
    counts[2]+=1
assert counts==[3750,1875,1875]
```
