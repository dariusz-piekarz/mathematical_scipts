## Kontrola pomocnicza FA26-SYM-124-01
Rzeczywiście uruchomiono poniższy skrypt w lokalnym Pythonie z Fraction. Dla 22 wymiernych punktów sfery euklidesowej i siedmiu dodatnich wymiernych promieni sprawdzono 23716 uporządkowanych przypadków (u,v,r,s). Tożsamość ||ru-sv||²=(r-s)²+rs||u-v||²; oszacowanie końcowe z Radona–Riesza ||ru-sv||<=r||u-v||+|r-s|, sprawdzone bez pierwiastków przez rozróżnienie znaku nadwyżki kwadratu; odwrotna nierówność trójkąta. Wynik [23716,23716,23716], 71148/71148 asercji. Jest to skończony model pomocniczy rachunku, nie dowód ogólnego twierdzenia ani formalizacja Lean. Kod zachowano w raporcie, bez modyfikacji istniejących regresji.

```python
from fractions import Fraction as F
from itertools import product
V=[((1-t*t)/(1+t*t),2*t/(1+t*t))
   for t in (F(k,5) for k in range(-10,11))]+[(F(-1),F(0))]
R=[F(k,4) for k in range(1,8)]
def sq(v): return sum(a*a for a in v)
counts=[0,0,0]
for u,v,r,s in product(V,V,R,R):
    x=tuple(r*a for a in u); y=tuple(s*b for b in v)
    d2=sq(tuple(a-b for a,b in zip(x,y)))
    q=sq(tuple(a-b for a,b in zip(u,v)))
    assert d2==(r-s)**2+r*s*q; counts[0]+=1
    A=r*r*q; B=(r-s)**2
    excess=d2-A-B
    assert excess<=0 or excess*excess<=4*A*B; counts[1]+=1
    assert d2 >= (r-s)**2; counts[2]+=1
print(counts,sum(counts))
```
