## Kontrola pomocnicza FA25-SYM-116-01
Rzeczywiście uruchomiono poniższy kod w lokalnym Pythonie z Fraction. W modelu kombinacji delt i ich pochodnych w trzech różnych punktach wymiernych porównano niezależnie działanie na iloczyn wielomianów z rozwinięciem Leibniza, zgodność mnożenia z ograniczeniem do podzbiorów punktów i łączność kolejnego mnożenia. Wynik [729, 5832, 2916], 9477/9477 asercji. Jest to skończony model rachunku, nie dowód twierdzeń topologicznych. Kod utrwalono jako odtwarzalną kontrolę pomocniczą w raporcie, nie jako nową metodę CI.

```python
from fractions import Fraction as F
from itertools import product
from math import factorial, comb
pts=(F(-1),F(0),F(2,3))
atoms=((0,2,F(3,2)),(1,1,F(-2,3)),(2,0,F(1,4)),(2,3,F(2)))
P=list(product((-1,0,1),repeat=3))
def mul(a,b):
    c=[F(0)]*(len(a)+len(b)-1)
    for i,x in enumerate(a):
        for j,y in enumerate(b): c[i+j]+=x*y
    return c
def jet(a,x,m):
    return sum(c*F(factorial(i),factorial(i-m))*x**(i-m)
               for i,c in enumerate(a) if i>=m)
def act(A,f):
    return sum(c*(-1)**m*jet(f,pts[i],m) for i,m,c in A)
def mult(a,A):
    return [(i,m-k,c*(-1)**k*comb(m,k)*jet(a,pts[i],k))
            for i,m,c in A for k in range(m+1)]
counts=[0,0,0]
for a,f in product(P,repeat=2):
    B=mult(a,atoms)
    assert act(B,f)==act(atoms,mul(a,f)); counts[0]+=1
    for mask in range(8):
        A0=[t for t in atoms if mask>>t[0]&1]
        B0=[t for t in B if mask>>t[0]&1]
        assert act(B0,f)==act(A0,mul(a,f));counts[1]+=1
    for b in (P[0],P[7],P[15],P[-1]):
        assert act(mult(b,B),f)==act(mult(mul(a,b),atoms),f)
        counts[2]+=1
print(counts,sum(counts))
```
