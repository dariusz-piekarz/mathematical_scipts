## Kontrola pomocnicza FA25-SYM-117-01
Rzeczywiście wykonano poniższy kod lokalnie w Pythonie z Fraction. Skończony model splotów kombinacji delt i ich pochodnych, porównanie dwóch nawiasowań, zawieranie nośnika w sumie Minkowskiego, niezależny rachunek działania na dżetach wielomianów. Wynik [27,27,6561], razem 6615/6615 asercji. Nie jest to dowód ciągłości splotu w przestrzeniach dystrybucji ani formalizacja Lean. Kod utrwalono w raporcie jako odtwarzalną kontrolę pomocniczą.

```python
from fractions import Fraction as F
from itertools import product
from math import factorial
A=[((F(-1,2),0,F(2)),(F(1,3),1,F(-1))),
   ((F(0),2,F(1,2)),(F(1),0,F(3))),
   ((F(-2),1,F(1)),(F(2,3),3,F(-2)))]
def conv(T,S):
    d={}
    for x,m,c in T:
        for y,n,b in S:
            key=(x+y,m+n)
            d[key]=d.get(key,F(0))+c*b
    return tuple((x,m,c) for (x,m),c in sorted(d.items()) if c)
def jet(p,x,k):
    return sum(a*F(factorial(i),factorial(i-k))*x**(i-k)
               for i,a in enumerate(p) if i>=k)
def act(T,p):
    return sum(c*(-1)**m*jet(p,x,m) for x,m,c in T)
counts=[0,0,0]
for T,S,U in product(A,repeat=3):
    L=conv(conv(T,S),U); R=conv(T,conv(S,U))
    assert L==R; counts[0]+=1
    assert {x for x,m,c in L}<={x+y+z for x,m,c in T for y,n,b in S for z,k,a in U}
    counts[1]+=1
    for p in product((-1,0,1),repeat=5):
        direct=sum(c*b*a*(-1)**(m+n+k)*jet(p,x+y+z,m+n+k)
                   for x,m,c in T for y,n,b in S for z,k,a in U)
        assert act(L,p)==direct; counts[2]+=1
print(counts,sum(counts))
```
