## Kontrola pomocnicza FA24-SYM-107-01
Rzeczywiście uruchomiono poniższy kod w Pythonie z Fraction. Dla trzech par wymiernych ciągów geometrycznych (w tym z naprzemiennymi znakami i identycznymi ilorazami), 81 par wektorów w R² z normą l1 i wszystkich wskazanych obcięć sprawdzono 13122 certyfikaty normy l1 bloków, 13122 oszacowań przez skończone sumy iloczynów norm oraz 13122 oszacowań tych sum przez dokładne nieskończone ogony geometryczne. Łącznie 39366/39366. Modele weryfikują rachunek ogonów i certyfikaty norm, nie dowodzą ogólnego twierdzenia o uzupełnionych iloczynach; nie są dodatkową metodą CI.

```python
from fractions import Fraction as F
from itertools import product
V=list(product(range(-1,2),repeat=2))
models=[(F(1,2),F(-1,3)),(F(-2,3),F(1,4)),(F(1,3),F(1,3))]
def l1(v): return sum(map(abs,v))
counts=[0,0,0]
for (r,s),y,z in product(models,V,V):
    rows=[tuple(r**n*y[j]+s**n*z[j] for j in range(2)) for n in range(10)]
    for N in range(9):
        tail_inf=abs(r)**N/(1-abs(r))*l1(y)+abs(s)**N/(1-abs(s))*l1(z)
        for M in range(N+1,11):
            block=rows[N:M]
            finite=sum(l1(v) for v in block)
            certificate=sum(t*((t>0)-(t<0)) for v in block for t in v)
            assert finite==certificate
            counts[0]+=1
            factor_bound=sum(abs(r)**n*l1(y)+abs(s)**n*l1(z) for n in range(N,M))
            assert finite<=factor_bound
            counts[1]+=1
            assert factor_bound<=tail_inf
            counts[2]+=1
assert counts==[13122,13122,13122]
```
