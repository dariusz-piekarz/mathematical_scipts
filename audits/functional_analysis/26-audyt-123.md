Model normowania z kroku trzeciego dowodu Eberleina–Šmuliana: M={(a,b,a+b)} w l-infinity^3, pierwsze dwie ewaluacje normują z czynnikiem 2; Psi=(0,0,c) anihiluje te ewaluacje. Dla 2197 trójek (a,b,c) sprawdzono trzy nierówności, w tym ||Psi|| <= 3 ||Psi-G||. Wynik [2197,2197,2197], razem 6591/6591 asercji, oraz dodatkowo jedna kontrola osiągania równości dla współczynnika 3. Model skończony ilustruje oszacowanie, nie dowodzi twierdzenia Eberleina–Šmuliana ani nie stanowi formalizacji. Kod utrwalono w raporcie jako odtwarzalną kontrolę pomocniczą, nie jako nową metodę CI.

```python
from fractions import Fraction as F
from itertools import product

def norm(v):
    return max(map(abs,v))

def sub(u,v):
    return tuple(a-b for a,b in zip(u,v))

values=[F(i,3) for i in range(-6,7)]
counts=[0,0,0]
for a,b,c in product(values, repeat=3):
    G=(a,b,a+b)
    psi=(F(0),F(0),c)
    err=norm(sub(G,psi))
    assert norm(G)<=2*max(abs(a),abs(b)); counts[0]+=1
    assert norm(G)<=2*err; counts[1]+=1
    assert norm(psi)<=3*err; counts[2]+=1
assert norm((0,0,3))==3*norm(sub((1,1,2),(0,0,3)))
print(counts, 'total',sum(counts),'sharp factor 3: verified')
```
